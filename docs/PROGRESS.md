- Uzun müddət bloklanmış "Currency & FX gündəlik cron" addımı frankfurter.dev ilə açıldı (bax `docs/decisions/0020-fx-daily-sync.md`): v1 (ECB-yalnız) AZN-i dəstəkləmədiyi üçün **v2** (açarsız, 164 valyuta, AZN daxil) seçildi. Yeni `FrankfurterClient` (`src/modules/currency-fx/frankfurter-client.ts`) və `FxSyncService` (`@Cron(EVERY_DAY_AT_6AM)` + server açılışında `onModuleInit` + əl ilə `POST /fx-rates/sync`) — yalnız hazırda istifadədə olan valyutalar (`accounts`/`users`/`goals`-dan `DISTINCT`) arasında hər cüt üçün hər iki istiqamətdə birbaşa kurs yazır, `getRate()`-in düz+tərs-fallback dizaynına toxunmadan. İnkişaf zamanı real API cavabının sənədləşmə xülasəsindən fərqli olduğu üzə çıxdı (obyekt yox, `{date,base,quote,rate}` massivi) — canlı `curl` ilə düzəldildi. Yeni asılılıq: `@nestjs/schedule`. Test-lərdə `FrankfurterClient` `overrideProvider` ilə əvəz olunur. İzolə edilmiş dev instansiyada real frankfurter-ə qarşı canlı təsdiqləndi (AZN→USD, USD→AZN sətirləri bugünkü tarixlə yarandı). 57 e2e test (11 fayl) yaşıl.
